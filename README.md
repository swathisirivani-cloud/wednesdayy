# 🍛 Spice Corner – Food Menu Website

A simple restaurant menu website built with HTML, CSS and JavaScript.

## Features
- Menu cards with veg / non-veg tags
- Category filters (Breakfast, Main Course, Snacks, Desserts, Drinks)
- Live search
- Add items to an order and see the running total
- Mobile-friendly design

## Files
- `index.html` – page structure
- `style.css` – design
- `script.js` – menu data and features

## Run it
Open `index.html` in a browser, or host it free with GitHub Pages
(Settings → Pages → Branch: main, / (root) → Save).
